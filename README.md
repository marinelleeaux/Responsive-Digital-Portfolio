
# Jan Marinelle | Responsive Digital Portfolio

**A Modern, Elegant, and Interactive Personal Portfolio Website**

Welcome to **Jan Marinelle's Digital Portfolio**, where creativity, technology, and innovation come together. This website showcases academic achievements, technical skills, professional experiences, and selected projects while reflecting a passion for continuous learning and growth in Information Technology.

Developed using **HTML5, CSS3, and JavaScript**, the portfolio combines modern design, interactive elements, and responsive layouts to provide a seamless and engaging user experience.

---

## About the Project

**Jan Marinelle Digital Portfolio** is a professionally designed personal website created to establish a strong online presence and highlight knowledge, creativity, and technical competencies in Information Technology.

The platform provides an organized presentation of educational background, academic accomplishments, professional experiences, and technical projects. It serves as a digital representation of personal qualifications and career aspirations for potential employers, collaborators, and professional connections.
